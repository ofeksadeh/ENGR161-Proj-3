# ENGR161-Proj-3
This is the code base for project #3 of Purdue's engineering honors class.

# Mission
Design and code a robot intended to deliver "packages" (objects of varying shapes and sizes) in the correct orientation to drop sites. The robot should be able to traverse rough grounds, follow marked paths, and detect the correct zone locations.

# Robot details
The robot is running on a Raspberry Pi 4 connected to buildhat module.
The robot will use a variety of digital and analog sensors, including hall sensors, accelerometers, light sensors, ultrasonic sensors, IR sensors, and more.
The body of the robot is constructed from Lego, and the entire thing runs on a 3000 mah NiMH battery
